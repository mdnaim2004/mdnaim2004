# Md Naim Babu – Premium AI/ML Portfolio

A modern, production-ready React + Vite portfolio with dark-mode-first glassmorphism, smooth Framer Motion animations, responsive layouts, and recruiter-focused sections.

## Tech

- React + Vite
- Tailwind CSS
- Framer Motion
- React Router
- React Icons

## Project Structure

```
src/
  components/
    layout/
    sections/
    ui/
  pages/
  assets/
  hooks/
  utils/
  constants/
public/
```

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run lint
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/) and import the repository.
3. Use defaults:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Deploy.
5. Add your custom domain if needed from Vercel project settings.
